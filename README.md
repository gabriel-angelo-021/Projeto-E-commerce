# 📌 Sobre o projeto

O **Projeto E-commerce** é um projeto completo de dados desenvolvido para simular a estrutura e as operações de uma empresa de comércio eletrônico.

O projeto acompanha todo o fluxo, desde a definição dos requisitos do negócio até a modelagem de dados, criação do banco de dados, consultas SQL, análises e construção de um dashboard no Power BI.

A proposta foi aplicar, em um único projeto, conhecimentos de:

- Banco de Dados
- Modelagem de Dados
- SQL
- MySQL
- Análise de Dados
- Power BI
- Git e GitHub

---

# 🎯 Objetivo

Construir uma estrutura de dados capaz de organizar e analisar informações relacionadas às operações de um e-commerce.

O projeto contempla:

- Clientes
- Produtos
- Pedidos
- Itens dos pedidos
- Pagamentos
- Estoque
- Fornecedores
- Entregas
- Avaliações

A partir desses dados são realizadas análises sobre vendas, clientes, produtos, estoque, pagamentos e entregas.

---
