## 📌 Sobre o projeto

O **Projeto E-commerce** foi desenvolvido com o objetivo de simular a estrutura de dados de uma empresa de comércio eletrônico, desde a definição dos requisitos do negócio até a criação do banco de dados, consultas SQL, análises e dashboard no Power BI.

O projeto foi desenvolvido seguindo uma sequência de etapas, permitindo aplicar conceitos de **modelagem de dados, banco de dados relacional, SQL e análise de dados** em um cenário próximo ao encontrado no mercado.

---

## 🎯 Objetivo

Construir uma solução de dados para uma empresa de e-commerce capaz de organizar e analisar informações relacionadas a:

- Clientes
- Produtos
- Pedidos
- Itens dos pedidos
- Pagamentos
- Estoque
- Fornecedores
- Entregas
- Avaliações

Além disso, o projeto permite realizar análises de vendas, clientes, produtos, estoque, pagamentos e entregas.

---

## 🏢 Cenário do negócio

A empresa possui uma operação de comércio eletrônico na qual os clientes podem realizar pedidos de produtos.

O sistema precisa controlar todo o fluxo da operação:

**Cliente → Pedido → Pagamento → Entrega**

Ao mesmo tempo, os produtos são relacionados ao estoque e aos fornecedores:

**Produto → Estoque → Fornecedor**

Também são registradas avaliações realizadas pelos clientes:

**Cliente → Avaliação → Produto**
